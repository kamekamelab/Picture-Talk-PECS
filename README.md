# Picture Talk PECS

PECSの「絵カードを相手に交換してコミュニケーションを成立させる」という考え方を参考にした、タッチ操作中心の教育用Webアプリです。

## 現在の構成
- Phase 1：1枚のカードを交換する
- Phase 2：自分から相手へカードを届ける
- Phase 3：複数のカードから選び、交換スペースへ移す
- Phase 4：Sentence Stripで文を作って交換する
- 生徒画面にはPhase切替や記録ボタンを表示しない
- 交換成立後に教師が「自分から／手助けあり」を記録

## カード編集
先生用設定から、カードを個別に追加・編集・削除できます。
- 端末内の写真・イラストをカード画像として設定
- 表示する文字を変更
- 読み上げる言葉を表示文字とは別に設定
- カテゴリを自由に変更・追加
- 画像がないカードは絵文字を表示

選択した写真は、ブラウザー内へ保存しやすい大きさに縮小してから端末内に保存します。

## 保存について
設定、カード、簡易記録はブラウザー内の localStorage に保存します。同じ端末・同じブラウザーで利用する想定です。ブラウザーデータの削除や端末変更では引き継がれません。画像を大量に登録すると保存容量の上限に達する場合があります。
