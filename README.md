# Picture Talk PECS

絵カードをタッチで選び、「選ぶ → 相手に伝える → 相手が応答する → 伝わる」という流れを体験するための試作Webアプリです。

## 現在の初期版
- タッチ操作のみ
- Phase 1〜3 の切替
- 絵カード選択
- 相手に伝える画面
- 相手側の「わかったよ」
- 「つたわった！」のフィードバック
- 音声読み上げ ON/OFF
- 「自分から」「手助けあり」「伝えた回数」の簡易記録
- 設定と記録はブラウザー内に保存
- 外部ライブラリなし

## 注意
本アプリはPECSの考え方を参考にした教育用の試作です。正式なPECS研修や個別の指導計画を置き換えるものではありません。
