# Picture Talk PECS

PECSの「絵カードを相手に交換してコミュニケーションを成立させる」という考え方を参考にした、タッチ操作中心の教育用Webアプリです。

## 現在の構成
- Phase 1：1枚のカードを交換する
- Phase 2：自分から相手へカードを届ける
- Phase 3：複数のカードから選び、交換スペースへ移す
- Phase 4：Sentence Stripで「ほしいです＋カード」を構成して交換する
- 生徒画面にはPhase切替や記録ボタンを表示しない
- Phase変更、カード枚数、Phase 1・2で使うカード、読み上げは先生用設定で変更
- 交換成立後に教師が「自分から／手助けあり」を記録
- 設定と簡易記録はブラウザー内に保存
- 外部ライブラリなし

## 操作
カードはタップでも選択できます。マウスや対応環境ではドラッグして「交換するところ」へ移すこともできます。

## 注意
本アプリはPECSの考え方を参考にした教育用試作であり、正式なPECS研修や個別の指導計画を置き換えるものではありません。
